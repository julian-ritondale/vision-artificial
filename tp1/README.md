## TP1

A gaze tracker that detects whether a person is looking at the screen.
When the person looks away, the application shows an alarm message telling them
to look back at the screen.

### Requirements

Before running TP1, make sure you have:

- Python installed.
- A working webcam.
- The required Python packages installed:
  - `opencv-python`
  - `mediapipe`
  - `numpy`
- The MediaPipe Face Landmarker task file downloaded.

### Run

From the repository root, run:

```bash
python tp1/main.py
```
